# horse-racing-sim

**!  This project is currently under active development  !**

Python-based horse racing simulation.

## Goal

Adapting [Umamusume's](https://umamusume.com/) race simulation on a global scale.

## Soon-to-be Features

- Run horse races on a racetrack of your choice
- Export race data in a readable format for your own uses (data analysis etc.)
- Save races and replay them whenever you want
- Create and save custom racetracks to run races on
- (Tent.) Watch and bet with fake in-game currency on randomly generated races

## Installation Steps

Work in progress, installation steps are subject to change.

Clone the repository:

```bash
git clone https://github.com/Mellophos/horse-racing-sim.git
```

Run `main.py`:

```bash
python main.py
```

Note that results will output to the terminal.
